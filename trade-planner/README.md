# 交易规划

Phase 5 使用已入库的日线信号、账户配置和调用方提供的持仓快照，生成
`TradePlan`。通过门槛时可附上与券商无关的限价订单意图，供后续草稿流程验证。

## 调用方式

从仓库根目录运行 Python，并把 `trade-planner/src` 加入 `PYTHONPATH`。
使用已初始化的 DuckDB 连接调用
`TradePlanService(db).generate_trade_plan(request)`。请求类型为
`PlanningRequest`，结果包含 `plan` 和可选的 `order_intent`。

`account_id` 和 `signal_id` 指定账户及已入库的日线信号。计划日期按
`America/Chicago` 计算。调用方提供交易日历，覆盖历史会话、执行日和之后的
财报窗口。当日完成判定首版使用芝加哥时间 15:00，提前收市日因此会等待
常规收盘时间。

入场需提供同账户、同标的的 USD 快照，包括净值、可用现金、股数、市值、
未完成订单状态、组合净值以及单股和板块敞口。财报读取 `corporate_event`，
`earnings_checked_through` 声明已核验到的日期。调用方另提供限价、止损
参考价、目标价和一小时信号。空仓重新入场需要明确设置 `reentry_candidate`。
保护性卖出可以另提供 `exit_limit_price`。

## 首版规则

- Vanguard 已持有个股时生成 `EXIT_ONLY`，无持仓时禁止买入并给出 `AVOID`。
  仅展示已配置的置换权重。VOO 和 QQQ 的独立择时规则仍待确定。
- Schwab 假跌破入场使用已提供的置信度。缺失时取假跌破和量能确认评分的较低值。
  两项形态评分仍须分别高于 70 和 60，入场置信度须达到 70 或更高的配置门槛。
- 入场小时线须同标的、同执行日，已完成且仍有效，并确认更高低点和站上 VWAP。
  默认小时线在收盘后 120 分钟内有效，账户快照最长有效 24 小时。
- 首先按单账户净值、可用现金、单笔规模、账户单股敞口和估算单笔风险确定股数，
  向下取整后再查组合单股 8% 和板块 25% 上限。组合数据缺失或超限时保持观察。
  参数在 `config/risk.yaml` 中配置。
- 个股财报禁入包含执行日及之后 5 个交易日，覆盖不足时保持观察。
- 连续两个已收盘交易日的收盘价低于各自 MA200 时提议 `EXIT`，单账户持仓
  超上限时估算减至上限的股数并提议 `REDUCE`。两者均要求可卖股数和未完成订单
  状态已确认。缺少卖出参考限价时，仅生成审核计划。

每个计划均有失效条件。相同输入复用计划 ID。同一账户、标的及计划日的输入发生
变化时生成新计划并引用上一版。计划和日线信号关联在同一事务中写入。
持仓、财报和小时线数据采集将在后续流水线阶段接入。
